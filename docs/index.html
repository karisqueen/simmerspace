Acerca de SimmerSpace

SimmerSpace es un prototipo bilingüe para gestionar visualmente el contenido de Los Sims 4. Esta pre-beta permite configurar las rutas del juego y revisar nombres de archivos de CC en modo de solo lectura.

Estado actual

Esta versión no se conecta a plataformas externas ni instala mods. Los perfiles, enlaces, estadísticas y elementos del catálogo son datos ficticios de demostración.
